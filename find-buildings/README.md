# Thirty-Sample Residential Layout Study

This directory defines a reproducible analysis of 30 anonymized or synthetic
residential plans. It does not compile identifiable occupied buildings or
site-specific security information.

## Files

- [datasets.md](datasets.md): approved source catalogue and governance checks.
- [layout-security-workflow.md](layout-security-workflow.md): end-to-end research workflow.
- [study-config.yaml](study-config.yaml): sample allocation and analysis configuration.
- `30-sample-study.md`: sampling and execution plan.
- `metric-schema.md`: normalized input and output contracts.
- `report-template.md`: individual and aggregate reporting format.

## Execution status

The research design and configuration are present. Dataset downloads and metric
results are not fabricated: they remain pending until the applicable terms are
accepted and the source data is lawfully obtained.
